# Active Contours GUI
A GUI impelementation of the active contours computer vision algorithm. The project was created solely in Python using Tkinter, for the GUI, and Python's Image Library (PIL), to get pixel data from the image.

## Usage

tkinter should now be a standard python library so to run this project all you should need to do is install `pillow` and run main as below:
```bash
pip install pillow

python3 main.py
```

## Dependencies
- tkinter
- pillow
